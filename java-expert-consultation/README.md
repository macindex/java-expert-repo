# Arquivos de consulta para Java Software Engineer Expert

Este conjunto foi organizado para estudo orientado a entrevista. A ideia é combinar teoria curta, sinais que o entrevistador procura e trechos de código que ajudam a explicar decisões técnicas com clareza.

## Ordem sugerida de estudo

1. [Java moderno e concorrência](01-java-modern-runtime.md)
2. [Spring, JPA e performance](02-spring-data-jpa-performance.md)
3. [Arquitetura, resiliência e idempotência](03-architecture-resilience.md)
4. [Mensageria e observabilidade](04-messaging-observability.md)
5. [Roteiro comportamental e narrativa de impacto](05-behavioral-playbook.md)

## Como usar

Leia cada arquivo em três passos:

1. Entenda o problema que a entrevista quer revelar.
2. Memorize os trechos de código e os trade-offs associados.
3. Treine a explicação em voz alta usando contexto, decisão e resultado.

## Regra prática

Em nível expert, a resposta precisa mostrar causa raiz, impacto no sistema e justificativa de negócio. O código abaixo serve como suporte de raciocínio, não como receita fixa.
